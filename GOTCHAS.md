# GOTCHAS.md — Build-a-blog

Traps that already bit this project. Read before editing. When one becomes a general rule it moves to AGENTS.md.

- **Historical archive**: known limitations are documented as learnings — don't silently "fix" history; new work is documented as new work.
- **Not fully audited**: comments/likes/contact flows have not had a security audit — don't describe the app as fully secure in copy.
- **No live backend**: the old Heroku deploy is retired; the README's local run instructions are the way to try it.
